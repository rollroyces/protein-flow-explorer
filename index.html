About Protein Flow Explorer

Protein Flow Explorer is a free, open teaching tool for visualising the 3D structures of proteins. It is designed to make molecular biology easy to understand and easy to explain — in a classroom, a presentation, or while reading a paper.

Three ways to explore

  • Controls. Switch representations (cartoon, surface, sticks, …) and colour schemes (chain, secondary structure, hydrophobicity, …) to inspect a structure from any angle.
  • Guided Tour. A scripted, step-by-step walkthrough that highlights the functional features of each curated protein. Great for teaching.
  • Trajectory. Play back a conformational change — hemoglobin T→R, kinase open→closed, calmodulin extended→compact — by sliding between two PDB states.

Load any molecule

Use the PDB ID input to fetch any structure from the open-access RCSB Protein Data Bank, or drop a .pdb / .cif file onto the drop zone to load AlphaFold models, your own simulations, or any local structure. Custom molecules stay in the library for the session and can be removed with the × button on each card.

Technology

  • Rendering: 3Dmol.js
  • Data: RCSB PDB (open-access)
  • Frontend: Vanilla HTML + CSS + JS, no build step

This is an educational tool, not for clinical use. Structure coordinates are fetched live from RCSB; an internet connection is required the first time a protein is opened.
